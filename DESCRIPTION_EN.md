# ImYOURhealer (English Description)

ImYOURhealer is a healer-focused WoW TBC Classic addon that automates party communication during dungeon runs.

It sends a configurable greeting when a run starts, tracks dungeon completion by endboss and/or full boss clear, and handles end-of-run follow-up messages automatically. The addon also supports heroic rerun suggestions, key-check logic, low-mana warnings with anti-spam cooldown, out-of-range alerts, and class-based cooldown announcements.

For paladins, ImYOURhealer integrates with PallyPower: players can be whispered their current blessing setup at run start, and they can request changes via whisper commands like `pp wisdom`, including automatic handling for useful 5-man scenarios.

Everything is configurable in a compact tabbed UI with German/English language support, test mode, minimap access, and persistent debug logs.

If you heal dungeons regularly and want cleaner, faster group coordination without repetitive typing, ImYOURhealer is built exactly for that.
